# Ganesh Patil — Personal Portfolio

Responsive dark-modern portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP and open the folder in VS Code.
2. Open `index.html` in a browser, or install the VS Code **Live Server** extension and choose **Open with Live Server**.
3. No build tools or package installation are required.

## Before publishing
- Add your latest résumé PDF to `resume/` and name it exactly `Ganesh_Patil_Resume.pdf`. The download link already points there.
- Project buttons currently link to your GitHub profile. Replace each with the exact repository URL when you have it.
- Add public certificate verification links if available.
- Review project descriptions and update anything that does not reflect your final work.
- The hero uses a code illustration; a profile photo is not required.

## Contact form
The form uses `mailto:`. It opens the visitor's email app with a pre-filled message; it does not submit to a server. For a hosted form that sends messages directly, connect a form service or backend.

## Deploy to GitHub Pages
1. Sign in to GitHub and create a **public** repository named exactly `ganesh21620-droid.github.io`.
2. Upload the *contents* of this folder to the repository root. Ensure `index.html` is at the root.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for the deployment, then visit: https://ganesh21620-droid.github.io

If that repository already exists, upload these files to it rather than creating a duplicate. To update the site later, edit the files and commit the changes to `main`.
